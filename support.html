Collie Support

Collie is a native iOS client for herdr. It needs herdr (herdr.dev) running on a Mac or Linux computer that your iPhone can reach over SSH.

Getting started

  1. Install herdr on the computer and open a project in it.
  2. Turn on Remote Login (macOS: System Settings > General > Sharing) or sshd (Linux).
  3. In Collie, add the computer: the onboarding walks you through the address, the sign-in and a connection test.

Notifications

Install the herdr-push plugin on the computer. Collie can install it for you from Settings > Notifications.

Purchases

Collie Pro is a one-time purchase. To move it to a new device, open Settings > Collie Pro and tap Restore Purchases.

Contact

Write to collie@estrella.cloud. Please include your device, the iOS version and the herdr version.
